WebMCP demo

This page registers three WebMCP tools for a small greenhouse. An AI agent in the browser can call them, and you can run them yourself from the tool console. Each browser tab gets its own greenhouse, kept in server memory. Nothing else in Rolnopol changes.

Session

Tools on this page

practice.greenhouse.getStatus

readOnlyHintuntrustedContentHint

Returns the beds, the harvest total and the notice board. Visitors write the notice board, and one note is a prompt injection, so the tool marks its output as untrusted.

practice.greenhouse.waterBed

changes state

Waters one bed. The agent runs it without asking you, and the beds below update.

practice.greenhouse.harvestBed

consequentialHint

Harvests a fully grown bed. You can't undo a harvest, so the page asks you to confirm first.
